# PCOM-SD-Wordpress

NNP Software Development (SD) component. Pinned upstream image `wordpress:7.1.4-php8.3-apache` republished under the NNP namespace. WordPress CMS; needs MySQL or MariaDB (for example `pcom-ds-mariadb`).

```
docker.io/nubonativesolution/pcom-sd-wordpress:7.1.4
```

Architecture: `linux/amd64`. CI/CD via the shared [PCOM-CICD](https://github.com/NNP-Platform-Components-PCOM/PCOM-CICD) reusable pipeline.
